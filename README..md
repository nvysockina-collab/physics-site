# Physics Site | Образовательный проект
> Интерактивный сайт с материалами по физике для учеников, учителей и родителей.

## ✨ Что внутри
- Материалы по темам (книги, ОГЭ, ЕГЭ)
- Тренажеры для подготовки к экзаменам
- Разделы для учеников и преподавателей

## 🚀 Как открыть
1. Скачайте проект или склонируйте репозиторий.
2. Откройте файл `index.html` в любом браузере.

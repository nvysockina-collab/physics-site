СПЕЦИФИКАЦИЯ ПРОЕКТА: ОБРАЗОВАТЕЛЬНЫЙ САЙТ ПО ФИЗИКЕ
=====================================================

1. КОНЦЕПЦИЯ
Статический образовательный сайт по физике для школьников 7–10 классов.
Сочетает три формата: теорию (конспекты), практику (интерактивные
тренажёры) и художественное чтение (книга «Физика в сказках»), где
физические законы объясняются через сказочные образы.

2. ЦЕЛЕВАЯ АУДИТОРИЯ
- Ученики — изучают теорию, тренируются, читают книгу.
- Учителя — используют материалы и тренажёры на уроках.
- Родители — помогают ребёнку и занимаются вместе с ним.

3. СТРУКТУРА
index.html                  — главная страница (7 кнопок-разделов)
detyam/index.html           — раздел для учеников
uchitelyam/index.html       — раздел для учителей
roditelyam/index.html       — раздел для родителей
trenazhery/index.html       — каталог тренажёров
    trenazher-kinematika.html, trenazher-dinamika.html, trenazher-mkt.html
materialy/index.html        — каталог теории
    mkt-teoriya.pdf, dinamika-teoriya.pdf, zakon-oma.pdf, statika-teoriya.pdf (конспекты в PDF)
book/book.html              — книга «Физика в сказках»
book/images/                — иллюстрации к книге
book/index.html, glossary.html, experiments.html — обложка, словарик, опыты
exams/index.html            — каталог «Подготовка к ОГЭ/ЕГЭ» (2 карточки)
    oge-index.html          — ОГЭ, 8–9 кл.: механические, тепловые,
                              электромагнитные, квантовые явления
    ege-index.html          — ЕГЭ, 10–11 кл.: механика, молекулярная физика,
                              электродинамика, оптика, квантовая физика
oge/, ege/                  — исходные сборники ФИПИ (PDF), материал для заданий

4. ТЕХНИЧЕСКИЕ ПРИНЦИПЫ
- Чистые HTML + CSS (+ JS только в тренажёрах), без сборки и серверов.
- Стили встроены в каждую страницу через <style>; внешний style.css
  не используется.
- Только относительные ссылки — сайт работает и с диска, и на хостинге.
- Адаптивная вёрстка (компьютер, планшет, телефон).
- Кодировка UTF-8, язык — русский.

5. КНИГА «ФИЗИКА В СКАЗКАХ»
- Содержание в начале книги со ссылками на каждую сказку.
- Заголовки сказок (h2) имеют id: vstuplenie, skazka-1 … skazka-13,
  chto-pochitat. Плавная прокрутка: html { scroll-behavior: smooth; }.
- Оформление блоков: .book-container (страница книги), .main-idea
  (главная мысль), .poem (стихи), .formula (формулы).

6. РАЗДЕЛ «ПОДГОТОВКА К ОГЭ/ЕГЭ»
- Вход с главной страницы: карточка «Подготовка к ОГЭ/ЕГЭ» (🎓).
- exams/index.html — выбор экзамена; oge-index.html и ege-index.html —
  карточки разделов с пометкой класса.
- Сейчас это каркас: ссылки карточек — «#», на карточках метка «Скоро».
  Дальше по каждому разделу будет своя страница с заданиями.
- Оформление — как в разделе «Теория» (белые карточки с цветной
  полосой сверху, класс .card, цвет задаётся через --c).

7. ПЛАНЫ РАЗВИТИЯ
- Новые тренажёры (оптика, электричество, термодинамика).
- Новые конспекты и сказки.
- Наполнение разделов для учителей (планы уроков) и родителей.

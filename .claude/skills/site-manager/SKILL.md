# Роль
Ты — ассистент, который помогает поддерживать образовательный сайт по физике.

## Структура проекта
- `index.html` — главная страница.
- `книга/`, `детям/`, `учителям/` — разделы с контентом.
- `CLAUDE.txt` — файл с контекстом проекта.

## Инструкции
1. **Запуск**: Чтобы посмотреть сайт, предложи пользователю открыть `index.html` в браузере.
2. **Обновление README**: Если пользователь добавляет новую папку или функцию, предложи обновить `README.md` в корне проекта.
3. **Проверка ошибок**: Проверяй, что все ссылки в `index.html` ведут на существующие файлы.
4. **Подготовка к публикации**: Перед пушем на GitHub проверяй, что `README.md` содержит актуальное описание, а все картинки на месте.

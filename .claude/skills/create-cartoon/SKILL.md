# Скилл: create-cartoon

## Назначение
Создание анимированного мультфильма по сказке в двух форматах:
1. Видеоролик `mp4` (для показа в классе без интернета).
2. Интерактивная страница для сайта (анимация + озвучка прямо в браузере).

Оба формата имеют общую основу: сценарий → раскадровка → кадры → озвучка.

## Правила безопасности
- Никогда не коммитить напрямую в master. Каждая публикация — отдельная ветка и PR.
- Перед коммитом всегда показывать дифф и ждать явного подтверждения пользователя.
- Существующие файлы репозитория не перезаписывать и не удалять.
- Не удалять и не менять тексты сказок: работать только со своими новыми файлами.
- Не запускать скачивание крупных библиотек без объяснения, зачем они нужны.

## Как использовать
1. Файл лежит в папке скиллов как `create-cartoon.md`.
2. Дать агенту доступ к локальной папке с материалами и к репозиторию.
3. Запускать скилл, когда есть: текст сказки (или указание, какую брать) и пожелания
   к длительности, стилю и голосу озвучки.

## Этап 0. Проверка окружения (обязательно, до любой работы)
Агент проверяет и докладывает пользователю одним сообщением:
- [ ] python 3 доступен, версия.
- [ ] ffmpeg доступен (команда `ffmpeg -version`). Без него mp4 не собрать — сообщить.
- [ ] TTS: пробует `edge-tts`. Если недоступен — устанавливает `pip install edge-tts`
      (объяснив, зачем). Если и это не сработало (нет интернета) — проверяет голоса
      Windows SAPI через PowerShell. Если нет ни того, ни другого — предложить
      пользователю вариант «без озвучки» (титры) или «записать свой голос» (см. Этап 3д).
- [ ] Сообщить пользователю: какой голос доступен, будет ли интернет-зависимость,
      и сколько это займёт по времени. Только после подтверждения — идти дальше.

## Этап 1. Сценарий и раскадровка
1. Прочитать исходную сказку (из репозитория или из папки пользователя).
2. Разбить на сцены (обычно 8–20 сцен для 2–5 минут ролика).
3. Для каждой сцены подготовить таблицу-раскадровку:
   | № | Описание кадра | Текст озвучки | Длительность (по числу слов) |
4. Показать раскадровку целиком и ждать подтверждения. Менять сценарий после
   подтверждения — только с явного согласия.

## Этап 2. Кадры
1. Рисовать сцены как SVG (персонажи, фон, реквизит) в едином стиле.
2. Стиль согласовать с сайтом: мягкие цвета, без фотографий, простые лица.
3. Все файлы кадров — в `cartoons/<имя-сказки>/assets/`.
4. Показать 2–3 кадра на просмотр до массовой отрисовки остальных.

## Этап 3. Озвучка
1. Основной путь: `edge-tts` с русским голосом (по умолчанию женский; голос и темп —
   по выбору пользователя). Сгенерировать пробный отрывок (1–2 предложения),
   дать пользователю прослушать mp3 ДО озвучки всего фильма.
2. Запасной путь: Windows SAPI через PowerShell (`System.Speech`), офлайн.
3. Путь 3д (по желанию пользователя): пользователь записывает свой голос по сценам;
   агент только обрабатывает и монтирует. Файлы ждать с именами `scene-01.mp3` и т.д.
4. Аудио по сценам — в `cartoons/<имя-сказки>/audio/`.
5. Хронометраж каждой сцены взять из фактической длительности mp3, а не из оценок.

## Этап 4. Сборка mp4
1. Собрать видео через ffmpeg: кадры + аудио по сценам, плавные переходы.
2. Параметры по умолчанию: 1280x720, 30 fps, субтитры — текст озвучки внизу кадра.
3. Итог: `cartoons/<имя-сказки>/movie.mp4`. Проверить, что размер разумный
   (до ~50 МБ на 5 минут; если больше — снизить битрейт).
4. Дать пользователю просмотреть ролик ДО публикации.

## Этап 5. Интерактивная версия для сайта
1. Собрать страницу `cartoons/<имя-сказки>/index.html`: анимация сцен,
   кнопка «Дальше», встроенный звук (audio-файлы тех же сцен).
2. Никаких внешних зависимостей: всё должно работать офлайн с GitHub Pages.
3. Навигация — обязательна, страница не должна быть тупиком:
   - вверху, над заголовком — ссылка возврата `← К сказкам` на `../../detyam/`;
   - внизу, в подвале — ссылка на книгу `← Книга «Физика в сказках»`
     на `../../book/book.html`.
   Пути относительные: страница лежит в `cartoons/<имя-сказки>/`, сайт —
   в подкаталоге GitHub Pages, поэтому абсолютные пути (`/detyam/`) ломаются.
   Шаблон (стиль ссылки возврата — как у «← На главную» на detyam/index.html):

   ```html
   <style>
   .back{display:inline-block;margin:0 0 14px;color:#4338ca;text-decoration:none;
     font-weight:600;font-size:15px;padding:7px 14px;border-radius:999px;background:#fff;
     box-shadow:0 3px 10px rgba(49,46,129,.13);transition:transform .15s,box-shadow .15s}
   .back:hover{text-decoration:underline;transform:translateY(-1px);
     box-shadow:0 6px 16px rgba(49,46,129,.2)}
   .back:focus-visible{outline:3px solid #f59e0b;outline-offset:2px}
   </style>

   <div class="wrap">
     <a class="back" href="../../detyam/">← К сказкам</a>
     <header>…заголовок…</header>
     …сцены, кнопки…
     <footer>
       <a href="../../book/book.html">← Книга «Физика в сказках»</a>
     </footer>
   </div>
   ```
4. Проверить обе ссылки по HTTP (например, `python -m http.server` из корня
   репозитория), а не только через `file://`: целевые страницы должны отвечать 200.
5. Показать пользователю страницу локально (открыть в браузере) до коммита.

## Этап 6. Публикация
1. Ветка `cartoon-<имя-сказки>`.
2. Коммит: файлы фильма, страницы, аудио, кадров.
3. Открывает PR с описанием и чек-листом:

   Что добавлено:
   - cartoons/<имя-сказки>/movie.mp4 (размер, длительность)
   - cartoons/<имя-сказки>/index.html
   - audio/ — N файлов
   - assets/ — N кадров

   Чек-лист:
   - [ ] Раскадровка была подтверждена пользователем
   - [ ] Пробная озвучка была прослушана и одобрена
   - [ ] Ролик просмотрен целиком перед публикацией
   - [ ] Страница проверена локально: анимация и звук работают
   - [ ] На странице есть «← К сказкам» вверху и ссылка на книгу внизу, обе открываются
   - [ ] Нет файлов больше 50 МБ
   - [ ] Существующие файлы не тронуты (дифф только добавления)

4. Если загружался мультфильм — предложить добавить блок на витрину
   (detyam/index.html или главную, по выбору пользователя) — по правилу 6
   из скилла safe-import-lessons. Страницу менять только через отдельную
   ветку и PR, с показом черновика блока.

## Критерии хорошего результата
- Пользователь трижды дал добро: на раскадровку, на пробную озвучку, на готовый ролик.
- mp4 открывается в стандартном плеере Windows без дополнительных кодеков.
- Страница работает офлайн: звук и анимация не зависят от интернета.
- Со страницы мультфильма можно уйти: вверху «← К сказкам», внизу — ссылка на книгу.
- В репозиторий не попало ничего лишнего (промежуточные кадры, кэш ffmpeg).
- Ссылка на мультфильм появилась на витрине (если пользователь согласился).
- Файлы ролика не перезаписали существующие страницы сайта.
